# تطبيق أور لتعلّم الفرنسية — iOS وAndroid

هذه تهيئة أولية لتطبيق Capacitor مرتبطة بمنصة الويب الحالية:
https://husseinmishbak.github.io/-/

## المتطلبات
- Node.js LTS وnpm
- Android Studio لتجميع Android
- macOS مع Xcode لتجميع iOS
- حساب Apple Developer / Google Play Console عند النشر في المتاجر

## إعداد المشروع
من داخل هذا المجلد:

```bash
npm install
npx cap add android
npx cap add ios
npx cap sync
npx cap open android
npx cap open ios
```

## ملاحظات مهمة
- هذه النسخة الأولى هي غلاف جوّال للمنصة المنشورة، وليست بعدُ حزمة متجر جاهزة أو نسخة تعمل دون إنترنت.
- يتطلب فتح المنصة والميزات المعتمدة على Supabase اتصالاً بالإنترنت.
- أمر `npx cap add ios` وتجميع iOS يتطلبان جهاز macOS مع Xcode؛ ويمكن تطوير Android على أنظمة أخرى.
- قبل النشر، يجب اختبار تسجيل الدخول، العودة من روابط التحقق، التسجيلات الصوتية، صلاحيات الميكروفون، اتجاه اللغات الثلاث، الروابط الخارجية، وسياسة الخصوصية على أجهزة فعلية.
- لا تضع مفاتيح Supabase السرية أو `service_role` داخل تطبيق الهاتف. استخدم المفتاح العام فقط مع سياسات RLS الصحيحة.
- يُفضّل في المرحلة التالية دمج ملفات الموقع داخل حزمة التطبيق بدلاً من الاعتماد على عنوان ويب بعيد، ثم إضافة خصائص أصلية مثل التسجيل الصوتي والإشعارات.
